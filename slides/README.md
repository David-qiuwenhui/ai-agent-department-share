# Slide-by-slide Collaboration Notes

This folder is reserved for slide-level drafts.

Recommended file naming:

- `01-opening.md`
- `02-agent-components.md`
- `03-workflow-vs-agent.md`

Each slide draft should include:

- slide goal
- audience takeaway
- visual structure
- editable PPT elements
- final on-slide copy
- speaker notes
