# AI Agent Department Share

This repository stores materials for a 30-minute department sharing session:

- Agent 原理科普
- AI 工具使用分享
- Vibe Coding 与个人 AI 工作流实践

## Collaboration Workflow

We will build the deck one slide at a time.

For each slide:

1. Brainstorm the slide goal and possible visual structures.
2. Finalize the slide copy and chart/table/diagram design.
3. Update the editable deck or slide source.
4. Commit the slide as a separate version.

## Files

- `ppt-page-design.md`: Current page-level deck design draft.
- `outputs/agent-ai-share-editable.pptx`: Editable PowerPoint draft.
- `outputs/agent-ai-share-editable-montage.png`: Rendered overview for quick review.

## Style Direction

- Corporate internal presentation style.
- High information density.
- Prefer diagrams and tables over paragraphs.
- Keep text and slide objects editable for later adjustment in PowerPoint.
