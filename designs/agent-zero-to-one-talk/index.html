从使用体验进入工程结构

Chat 模式

你问，我答
1
描述问题把上下文一次性交给模型
2
得到回答解释、总结、生成一段内容
3
人决定下一步继续追问、复制结果、手动执行

擅长把话说清楚；任务推进仍主要靠人接力。

差异不在
模型名字

Agent 模式

给目标，跑闭环
1
理解目标把“要达成什么”放进任务现场
2
选择行动读资料、调工具、拆计划、请求确认
3
观察结果把工具输出带回上下文继续判断
4
调整并收束反复推进，直到结果可交付

价值不是“更会聊天”，而是让复杂工作变成可观察、可控制的循环。

Context 管这次任务现场，Memory 管长期有用事实

s08 Context Compact + s09 Memory

短期上下文：会满，需要压缩

用户：请对比两条电子流 A 和 B。
工具：读取 A 的当前节点、停留时长和字段版本。
工具：读取 B 的归档节点、归档依据和字段版本。
压缩摘要：A 仍在复核中且停留 18 小时，B 已归档，字段版本不一致。
旧日志：中间查询参数、无关字段、重复响应。

长期记忆：只保存可复用事实

偏好部门分享偏好高信息密度图表，少用营销式页面。
项目事实本次材料主题是 Agent 原理科普和 AI 工具使用分享。
决策讲解采用由简到繁的能力层级，而不是按产品功能罗列。
